Cliplift — Complete Product & Technical Plan
Context
We're building Cliplift, a short-form video analytics + publishing tool positioned as the "anti-credit" alternative to Virlo.ai. Virlo's weaknesses: credit-gated pricing, narrow platform coverage, no publishing. Our edge: flat-rate unlimited pricing, insight-to-publish loop, and multi-platform parity.

Data strategy — three-tier model:

The entire competitive analytics market (including Virlo) runs on scraping and third-party data APIs. Virlo literally advertises "Custom Niches scrape TikTok, IG Reels, and YT Shorts 24/7." The API constraint is a shared constraint across the market, not a barrier.

TIER 1: OFFICIAL APIs (your own connected accounts — publishing + own analytics)
├── YouTube Data API v3        Free, 10K quota/day
├── Instagram Graph API        Business accounts only (submit app review in Week 0)
└── LinkedIn Marketing API     Publish + own page analytics (apply for partner access)

TIER 2: THIRD-PARTY DATA APIs (competitive intelligence on OTHERS — MVP stage)
├── Netrows (LinkedIn + X)     €49/mo, 10K credits, 48+ endpoints
├── Data365 (TikTok + IG)     $99/mo, videos/creators/hashtags/trends
└── YouTube Data API v3        Free (also covers competitive search)
    Total: ~$155/mo for 4-platform competitive intelligence

TIER 3: OWN SCRAPERS (build at >$5K MRR to reduce per-unit cost)
├── Playwright + residential proxies
├── Build per-platform only when volume justifies it
└── Swap in via DataProviderRouter without touching business logic
All data sources abstracted behind a DataProviderRouter adapter pattern. This is insurance — not over-engineering.

LinkedIn wedge reframed: The moat isn't "we have API access" (anyone can sign up for Netrows). The moat is "we make LinkedIn video data actionable" — benchmarking by industry, cross-platform trend correlation, B2B-specific outlier detection, publishing loop. Data is commodity; the insight layer is the moat.

Infra: FastAPI on Railway (auto-sleep) + QStash for scheduled tasks + Supabase (Postgres) + Upstash Redis + Vercel for frontend. No persistent workers. Timeline: Week 0 setup + 6 build weeks (honest estimate — Week 3 analytics and Week 4 publishing each deserve a full week).

Break-even: ~$162/mo total costs. Average revenue per user ~$50/mo. Break-even at 4 paying users. Per-user data cost ~$3/mo → 90% gross margin.

1. Product Vision
One-liner: "Discover what's going viral, publish your response, measure the results — one tool, flat rate, no credits."

Target users (MVP):

Solo creators (10K–100K followers) posting Shorts + Reels
Small agencies (5–15 clients) managing short-form across platforms
B2B growth teams using short-form for brand awareness
Pricing:

Tier	Price	Includes
Creator	$29/mo	Unlimited searches, 1 platform, 1 user, 3 tracked creators
Team	$79/mo	Unlimited searches, all platforms, 5 users, 25 tracked creators, scheduling
Agency	$149/mo	Everything + API access, 50 tracked creators, white-label reports
Annual billing: 30% discount. No credits. Ever.

4. Database Schema
Core Tables
-- AUTH & ACCOUNTS
-- users table references Supabase auth.users (no custom auth code)
-- Supabase handles: registration, login, OAuth, email verification, password reset
profiles (
  id UUID PK REFERENCES auth.users(id),  -- Supabase auth user ID
  email VARCHAR UNIQUE NOT NULL,
  name VARCHAR,
  avatar_url VARCHAR,
  stripe_customer_id VARCHAR,
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
)

teams (
  id UUID PK,
  name VARCHAR NOT NULL,
  owner_id UUID FK → profiles,
  plan VARCHAR DEFAULT 'creator',     -- creator | team | agency
  stripe_subscription_id VARCHAR,
  max_tracked_creators INT DEFAULT 3,
  max_seats INT DEFAULT 1,
  created_at TIMESTAMPTZ
)

team_members (
  id UUID PK,
  team_id UUID FK → teams,
  user_id UUID FK → profiles,
  role VARCHAR DEFAULT 'member',      -- owner | admin | member
  invited_at TIMESTAMPTZ,
  joined_at TIMESTAMPTZ
)

-- PLATFORM CONNECTIONS (OAuth tokens for publishing)
platform_connections (
  id UUID PK,
  team_id UUID FK → teams,
  platform VARCHAR NOT NULL,          -- youtube | instagram
  platform_user_id VARCHAR,
  platform_username VARCHAR,
  access_token TEXT,                   -- AES-256 encrypted at app layer (cryptography.fernet)
  refresh_token TEXT,                  -- AES-256 encrypted at app layer
  token_expires_at TIMESTAMPTZ,
  scopes VARCHAR[],
  connected_at TIMESTAMPTZ
)

-- CREATOR TRACKING
creators (
  id UUID PK,
  platform VARCHAR NOT NULL,          -- youtube | instagram | tiktok | linkedin
  platform_id VARCHAR NOT NULL,       -- channel ID / user ID
  username VARCHAR,
  display_name VARCHAR,
  avatar_url VARCHAR,
  bio TEXT,
  is_active BOOLEAN DEFAULT true,
  last_scraped_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ,
  UNIQUE(platform, platform_id)
)

creator_trackings (
  id UUID PK,
  team_id UUID FK → teams,
  creator_id UUID FK → creators,
  tracked_at TIMESTAMPTZ,
  notes TEXT
)

creator_snapshots (
  id UUID PK,
  creator_id UUID FK → creators,
  followers INT,
  total_videos INT,
  avg_views_30d FLOAT,
  avg_engagement_30d FLOAT,           -- (likes+comments) / views
  snapshot_date DATE NOT NULL,
  raw_data JSONB,                     -- full API response
  UNIQUE(creator_id, snapshot_date)
)

-- VIDEO TRACKING
videos (
  id UUID PK,
  creator_id UUID FK → creators,
  platform VARCHAR NOT NULL,
  platform_video_id VARCHAR NOT NULL,
  title VARCHAR,
  description TEXT,
  thumbnail_url VARCHAR,
  duration_seconds INT,
  published_at TIMESTAMPTZ,
  hashtags VARCHAR[],
  is_short BOOLEAN DEFAULT true,
  -- Creator-relative outlier score (is this above THIS creator's norm?)
  outlier_score FLOAT,
  is_outlier BOOLEAN DEFAULT FALSE,
  -- Denormalized latest metrics (avoids joins on every dashboard query)
  latest_views BIGINT DEFAULT 0,
  latest_likes BIGINT DEFAULT 0,
  latest_comments BIGINT DEFAULT 0,
  latest_shares BIGINT DEFAULT 0,
  latest_engagement_rate FLOAT,
  latest_snapshot_at TIMESTAMPTZ,
  last_scraped_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ,
  UNIQUE(platform, platform_video_id)
)

video_snapshots (
  id UUID PK,
  video_id UUID FK → videos,
  views BIGINT,                        -- BIGINT: viral videos exceed 2.1B (INT max)
  likes BIGINT,
  comments BIGINT,
  shares BIGINT,
  engagement_rate FLOAT,
  view_velocity FLOAT,                -- views per hour since last snapshot
  snapshot_at TIMESTAMPTZ,
  raw_data JSONB
)

video_trackings (
  id UUID PK,
  team_id UUID FK → teams,
  video_id UUID FK → videos,
  tracked_at TIMESTAMPTZ
)

-- NICHE / TREND DISCOVERY
niches (
  id UUID PK,
  team_id UUID FK → teams,
  name VARCHAR NOT NULL,
  keywords VARCHAR[] NOT NULL,        -- search terms
  platforms VARCHAR[] DEFAULT '{youtube,instagram,linkedin,tiktok}',
  is_active BOOLEAN DEFAULT true,
  last_analyzed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ
)

niche_videos (
  id UUID PK,
  niche_id UUID FK → niches,
  video_id UUID FK → videos,
  outlier_score FLOAT,                -- Z-score vs niche baseline
  discovered_at TIMESTAMPTZ
)

-- PUBLISHING & SCHEDULING
scheduled_posts (
  id UUID PK,
  team_id UUID FK → teams,
  connection_id UUID FK → platform_connections,
  created_by UUID FK → profiles,           -- who created (team audit trail)
  inspired_by_video_id UUID FK → videos,  -- the outlier that inspired this post (insight→action link)
  platform VARCHAR NOT NULL,
  title VARCHAR,
  description TEXT,
  hashtags VARCHAR[],
  file_key VARCHAR,                   -- R2 object key from presigned upload
  media_url VARCHAR,                  -- full URL (generated from file_key at publish time)
  scheduled_for TIMESTAMPTZ NOT NULL,
  status VARCHAR DEFAULT 'draft',     -- draft | scheduled | publishing | published | failed
  platform_post_id VARCHAR,           -- ID after publishing
  error_message TEXT,
  published_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
)

-- ANALYTICS (for user's own published content)
post_analytics (
  id UUID PK,
  post_id UUID FK → scheduled_posts,
  views INT,
  likes INT,
  comments INT,
  shares INT,
  watch_time_seconds INT,
  avg_view_duration FLOAT,
  snapshot_at TIMESTAMPTZ,
  raw_data JSONB
)

6. API Design
Auth (handled by Supabase — no custom endpoints)
# Frontend calls Supabase Auth SDK directly:
#   supabase.auth.signUp(), signInWithPassword(), signInWithOAuth({provider:'google'})
#   supabase.auth.signOut(), resetPasswordForEmail(), etc.
#
# Backend validates Supabase JWT on every request:
#   Authorization: Bearer <supabase_jwt>
#   → dependencies.py: get_current_user() validates token, returns user

GET    /api/v1/profile                → current user profile
PUT    /api/v1/profile                { name, avatar_url } → update profile
Pagination (all list endpoints use cursor-based pagination)
# Standard query params on all list endpoints:
?limit=20&cursor=<base64_encoded_cursor>

# Response shape:
{
  "items": [...],
  "next_cursor": "eyJjcmVhdGVkX2F0IjoiMjAyNi0wNC0wMyIsImlkIjoiYWJjIn0=",
  "has_more": true
}
Platform Connections
GET    /api/v1/connections             → list connected accounts
POST   /api/v1/connections/{platform}/authorize  → OAuth redirect URL
GET    /api/v1/connections/{platform}/callback    → OAuth callback
DELETE /api/v1/connections/{id}
Trend Discovery (PUBLIC — no auth required for search, paywall on tracking/publishing)
POST   /api/v1/discover/search        { query, platforms[], sort_by, date_range }  ← PUBLIC, rate-limited
GET    /api/v1/discover/trending       ?platform=&niche_id=&limit=                 ← PUBLIC
GET    /api/v1/discover/outliers       ?platform=&min_score=3.0                    ← PUBLIC
POST   /api/v1/discover/generate-idea  { video_id } → AI content brief            ← AUTH REQUIRED

7. Core Algorithms
Outlier Detection (the "magic")
# For each video in a niche search result:
# 1. Calculate baseline = median views for videos in that niche (last 30 days)
# 2. Calculate std_dev of views in niche
# 3. outlier_score = (video_views - baseline) / std_dev  (Z-score)
# 4. Flag videos with outlier_score >= 3.0 (3 standard deviations above mean)
#
# This is Virlo's "Outlier Analysis" — but ours runs on every search, unlimited.
View Velocity Tracking
# For tracked videos, snapshot every 6 hours:
# velocity = (current_views - previous_views) / hours_elapsed
# Acceleration = current_velocity - previous_velocity
# Flag "accelerating" videos (velocity increasing = going viral NOW)

12. Honest Moat Assessment
With third-party APIs, data access itself is NOT a moat. Anyone can sign up for Netrows. So what IS our moat?

Real moats (defensible)
Accumulated snapshot data. Every day we run, we accumulate historical trend data. A competitor starting 6 months later has 6 months less history. This compounds.
AI enrichment quality. Raw metrics are commodity. Our outlier scoring, hook analysis, topic clustering, and cross-platform trend correlation get better with more data. The algorithm IS the product.
Publishing + measurement loop. Requires OAuth integrations per platform. 2-4 weeks engineering per platform. Most analytics-only tools won't build this because it changes their product category.
Switching cost via workflow integration. Once a team's content calendar, alert rules, and tracked creators live in Cliplift, switching means rebuilding manually.
Not moats (but still advantages)
Flat-rate pricing (easily copied, but Virlo hasn't changed in 18+ months)
LinkedIn coverage (gettable by competitors, but nobody has bothered)
Free tools for SEO (commodity tactic, but effective for acquisition)
